Premier League Analytics Architecture

DB-first ingestion pipeline · API-Football → SQLite → tactical analytics & Tableau dashboards

Ingestion Pipeline

  • • Three entity pipelines: fixtures, lineups, transfers
  • • Cache-first: skip API when SQLite has data
  • • ~100 req/day API limit — batching & sleep flags
  • • Every run tracked in ingestion_runs table

Data Store

  • • SQLite system of record (teams, players, fixtures)
  • • Raw JSON archived under data/raw/
  • • Formation read-models under data/processed/
  • • PostgreSQL vars in .env.example — not wired yet

Consumption & Roadmap

  • • Tableau transfer dashboard (prototypes/tableau/v1)
  • • Formation matchup JSON for tactical analysis
  • • Planned: FastAPI service layer
  • • No ML training or prediction API yet
